## About This Repository

This repository contains Java programming exercises categorized by topic for easier navigation and learning.

Each problem is organized in its own folder and includes:

- `README.md` containing the problem summary and solution approach
- `Solution.java` containing the accepted Java solution

---

## Solution Format

Most solutions are preserved in the format required by the GeeksforGeeks online judge. As a result, some source files may not include driver code, import statements, or a `main()` method because these components are provided by the platform during execution.

The primary focus of this repository is to showcase problem-solving approaches, Java concepts, and accepted solutions.
