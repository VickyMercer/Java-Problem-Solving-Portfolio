# 07. Evaluate Logical Operations

## Problem Overview

Given two boolean values, evaluate the results of fundamental logical operations. The program should determine the outcomes of logical AND, logical OR, and logical NOT based on the provided inputs.

## Approach

Apply the logical operators to the input boolean values. Compute the results for AND (`&&`), OR (`||`), and NOT (`!`) operations, then return them in the required format.

## Time Complexity

**O(1)**

## Space Complexity

**O(1)**

## Key Learning Points

- Understanding boolean data types in Java.
- Using logical operators such as `&&`, `||`, and `!`.
- Evaluating conditions based on truth values.
- Formatting multiple results into a single output string.
