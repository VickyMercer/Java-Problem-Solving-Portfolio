# 03. Print Strings in a Single Line

## Problem Overview

Given two input strings, display them on a single line with a space separating them. The output should be properly formatted so that both values appear together as a single message.

## Approach

Read both strings from the input and concatenate them with a space in between before printing the result.

## Time Complexity

**O(n + m)**

Where **n** and **m** represent the lengths of the two input strings.

## Space Complexity

**O(1)**

## Key Learning Points

- Reading string input using `Scanner`.
- Combining multiple strings into a single output.
- Using string concatenation for output formatting.
- Understanding basic console input and output operations.
