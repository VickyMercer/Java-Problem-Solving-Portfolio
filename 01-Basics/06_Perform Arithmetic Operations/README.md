# 06. Perform Arithmetic Operations

## Problem Overview

Given two integers, perform a set of basic arithmetic operations and display the results. The operations include addition, subtraction, multiplication, floating-point division, integer division, and finding the remainder after division.

## Approach

Read the two integer values and compute the required arithmetic results using Java's built-in arithmetic operators. Store each result in a separate variable and print them in the specified format.

## Time Complexity

**O(1)**

## Space Complexity

**O(1)**

## Key Learning Points

- Using arithmetic operators in Java.
- Understanding the difference between integer and floating-point division.
- Performing modulo operations to obtain remainders.
- Formatting output using `System.out.printf()`.
