# 04. Print Strings with a Custom Separator

## Problem Overview

Given two strings and a separator symbol, combine the strings into a single output by placing the separator between them. The resulting text should be displayed exactly in the required format.

## Approach

Read the two input strings along with the separator, then concatenate them in the correct order by inserting the separator between the strings before printing the final result.

## Time Complexity

**O(n)**

## Space Complexity

**O(n)**

## Key Learning Points

- Reading multiple string inputs from the user.
- Combining strings using a custom separator.
- Formatting output according to specified requirements.
- Understanding the cost of string concatenation.
