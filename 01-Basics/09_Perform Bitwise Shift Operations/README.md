# 09. Perform Bitwise Shift Operations

## Problem Overview

Given two integers, perform both right and left bitwise shift operations on the first integer using the second integer as the shift count. Display the resulting values after each shift operation.

## Approach

Use the right shift operator (`>>`) to shift the bits of the first integer to the right and the left shift operator (`<<`) to shift the bits to the left by the specified number of positions. Print both results in the required format.

## Time Complexity

**O(1)**

## Space Complexity

**O(1)**

## Key Learning Points

- Understanding left shift (`<<`) and right shift (`>>`) operators.
- Observing how bitwise shifts affect binary representations.
- Using bitwise operations for efficient arithmetic computations.
- Working with low-level data manipulation in Java.
- Interpreting the relationship between shifting bits and powers of two.
