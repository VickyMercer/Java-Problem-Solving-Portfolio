01. Hello World
Problem Overview
Write a Java program that prints the message "Hello World" to the console. This introductory exercise helps familiarize developers with the basic structure of a Java application and simple output statements.

Approach
Use Java's standard output method to display the required text exactly as specified.

Time Complexity
O(1)

Space Complexity
O(1)

Key Learning Points
Understanding the basic structure of a Java program.
Identifying the role of the main() method.
Printing output to the console.
Writing the first executable Java application.
