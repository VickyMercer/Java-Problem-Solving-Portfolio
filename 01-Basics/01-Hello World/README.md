# 01. Hello World

## Problem Overview

Create a Java program that displays the message **"Hello World"** on the console. This introductory exercise helps in understanding the basic structure of a Java application and how output is printed to the screen.

## Approach

Use Java's standard output statement to print the required message exactly as specified.

## Time Complexity

**O(1)**

## Space Complexity

**O(1)**

## Key Learning Points

- Understanding the basic structure of a Java program.
- Learning the purpose of the `main()` method.
- Printing output using `System.out.println()`.
- Building and running a simple Java application.
