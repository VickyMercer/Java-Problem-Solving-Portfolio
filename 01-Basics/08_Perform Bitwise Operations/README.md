# 08. Perform Bitwise Operations

## Problem Overview

Given three integers, apply a series of bitwise operations and determine the resulting values. The task involves using XOR, AND, and bitwise complement operators to manipulate the binary representations of the numbers and produce the required output.

## Approach

Perform each bitwise operation in the specified order and store the results in separate variables. Once all computations are complete, print the values in the required format.

## Time Complexity

**O(1)**

## Space Complexity

**O(1)**

## Key Learning Points

- Understanding bitwise XOR (`^`) operations.
- Using bitwise AND (`&`) to compare individual bits.
- Applying the bitwise complement (`~`) operator.
- Working with binary-level manipulation in Java.
- Observing how bitwise operations affect integer values.
